# 🎮 Rock Paper Scissors Game

![Rock Paper Scissors Game](https://assets.skyfilabs.com/images/blog/rock-paper-scissor-game-using-python.webp)

A simple Python command-line Rock Paper Scissors game where the player competes against the computer.

The computer randomly chooses Rock, Paper, or Scissors, and the player enters their choice.

## 📌 Features

- Play Rock Paper Scissors against the computer.
- Computer makes a random choice.
- Player enters their choice through `input()`.
- Determines whether the player wins, loses, or ties.
- Displays the computer's choice and the result.
- Simple command-line interface.

## 🛠️ Technologies Used

- Python 3
- `random` module
- `random.choice()`
- `while` loops
- `if / elif / else`
- `input()`
- Variables
- Lists
- f-strings
